## jay-session

긴 작업은 컨텍스트 한 창을 넘깁니다. 흔한 해법인 `/compact` 는 정보를 버리는 데다, 하필 컨텍스트가 가장 무거운 — 즉 잃을 게 가장 많은 — 순간에 터집니다. 이 플러그인은 반대로 갑니다. **지우기 전에** 남길 것을 적어두고, 그걸 다음 세션에 자동으로 넘깁니다.

### 기능

| 기능 | 하는 일 |
|---|---|
| **인계 (handoff)** | 대화와 git 상태를 훑어 `handoff-*.md` 작성. **시도했다 실패한 것**까지 남기며, 이건 `git log` 가 절대 알려주지 않습니다 |
| **`/clear` 자동 인계** | `SessionStart` 훅이 방금 쓴 인계 문서를 새 세션에 밀어넣습니다. 프롬프트 복붙이 사라집니다 |
| **개발일지 (devlog)** | 매 턴의 요청·결과·변경 파일이 `devlog.md` 에 자동으로 쌓입니다. 프로젝트별 선택 |
| **결정 기록** | 항목에 `**결정:**` 한 줄을 남기면 나중에 결정만 뽑아볼 수 있습니다 |
| **압축 보험** | auto-compact가 터져도 압축 전 원본 대화 파일 경로가 남습니다 |

### 설치

```bash
claude plugin marketplace add jaymunsh/jay-claude
claude plugin install jay-session@jay-claude
```

Claude Code를 재시작(또는 새 세션 시작)하세요. 명령어와 훅은 세션 시작 시점에 로드됩니다.

`python3` 이 필요하며, macOS와 대부분의 리눅스에 기본 포함돼 있습니다.

### 사용법

**세션을 마무리할 때:**

```
/jay-new
```

지금까지의 작업을 정리해 `.claude/session/handoff-YYYYMMDD-HHMM.md` 를 쓰고, **정말로 추론이 안 되는 것만** 물어봅니다. 그다음 직접 `/clear` 를 치면 새 세션이 이미 맥락을 알고 시작합니다.

범위를 좁힐 수도 있습니다: `/jay-new 인증 리팩터링만`

**개발일지 켜기** (선택, 프로젝트별):

```
/jay-init
```

다음 턴부터 모든 작업이 `.claude/session/devlog.md` 에 쌓입니다. 이것만 명시적 동의를 받는 이유는 **매 턴 파일이 쌓이는 동작**이기 때문입니다. 묻지도 않았는데 저장소에 파일이 늘어나면 안 되니까요.

**나머지는 그냥 말하면 됩니다.** 명령어가 필요 없습니다:

- "지난번 거 이어서 하자" → 최신 인계 문서를 읽고 `git status` 로 검증한 뒤 브리핑
- "지난주에 그 타임아웃 에러 어떻게 고쳤지?" → devlog 검색
- "이건 남겨줘" → 훅이 못 잡는 판단 근거까지 수동으로 기록

### 생기는 파일

**요청하기 전까지는 아무것도 안 생깁니다.** `/jay-new` 가 처음 쓰일 때 디렉터리를 만들고, devlog 훅은 `devlog.md` 가 없으면 즉시 종료합니다.

```
<프로젝트>/.claude/session/
├── handoff-20260806-2230.md   # 누적. 최신 것을 사용
├── devlog.md                  # 이번 달. 이 파일 존재 여부 = devlog 켜짐/꺼짐 스위치
├── devlog-2026-07.md          # 지난 달들, 자동 분리
└── .devlog-state              # 훅 중복 방지 커서
```

디렉터리를 처음 만들 때 `.gitignore` 에 `.claude/session/` 을 넣을지 **한 번만** 물어봅니다. 기본은 넣기 — 개인 작업 흐름이라 커밋 로그와 중복되고, devlog는 매 턴 커져서 diff를 오염시킵니다. 팀과 인계 문서를 공유할 목적이면 빼세요.

### 동작 원리

훅 3개, 스크립트 1개.

| 훅 | 발동 시점 | 하는 일 |
|---|---|---|
| `Stop` | 매 턴 종료 | devlog에 append, 월별 자동 분리. devlog가 꺼져 있으면 즉시 종료 |
| `SessionStart` (`clear`, `compact`) | 지운 뒤 새 세션 | 30분 내 작성된 인계 문서를 주입 |
| `PreCompact` | 컨텍스트 압축 직전 | 압축 전 원본 대화 파일 위치를 기록 |

30분 제한이 소음을 막는 장치입니다. **인계 문서를 방금 썼다는 것 자체가 "이어서 하겠다"는 신호**라, 오래된 문서가 무관한 세션에 끌려 들어오지 않습니다.

`PreCompact` 가 사본이 아니라 경로만 남기는 건 의도적입니다. 압축은 모델의 컨텍스트만 지우고 대화 파일은 디스크에 그대로 남습니다. 그러니 필요한 건 복사본이 아니라 "원본이 어디 있는지"입니다.

판단이 필요한 일(인계 문서에 뭘 담을지, devlog 검색 결과를 어떻게 요약할지)은 `session-manager` 스킬에, 기계적인 일은 훅에 두었습니다. 훅에 둔 덕분에 세션이 길어져도 "기록해야지"를 잊을 일이 없습니다.

### 끄기

```bash
rm .claude/session/devlog.md    # devlog 중단 (기록이 지워지니 남길 게 있으면 먼저 옮기세요)
claude plugin uninstall jay-session@jay-claude
```

제거하면 훅과 명령어가 사라집니다. 이미 쓰인 `.claude/session/` 파일은 그대로 남습니다.

### 참고

- 사용자의 `settings.json` 을 건드리지 않습니다. 훅이 플러그인 안에 실려 있어서 다른 플러그인·훅과 충돌하지 않습니다.
- 세션 도중에 devlog를 켜면 **그다음 턴부터** 기록됩니다. 이미 지나간 앞부분은 복구되지 않습니다.
